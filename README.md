# Loan Approval Prediction

Predicts whether a loan application will be approved using ML classification algorithms.

## Tech Stack
Python, Pandas, Scikit-learn, Matplotlib, Seaborn, Google Colab

## Models Compared
| Model | Accuracy |
|-------|----------|
| Logistic Regression | 78.86% |
| Naive Bayes | 78.86% |
| Random Forest | 76.42% |
| Decision Tree | 72.36% |
| SVM | 65.04% |

## Best Model
Logistic Regression — 78.86% accuracy

## Dataset
Kaggle - Loan Prediction Problem Dataset (614 records, 12 features)
